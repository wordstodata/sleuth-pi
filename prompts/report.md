Write the end-of-run report for this session, following the playbook's Report
section (skills/references/working-a-dataset.md):

1. What you were asked, and your answer with its evidence — quote the words at
   both ends of each change from tool output.
2. Each record you wrote (link, no-link, review verdict) with its id.
3. Each item you left alone, and why.
4. Anything the commands could not tell you — the tool's gaps. Run
   `/sleuth-gaps` and include every recorded gap as a finding to file against
   words-to-data, with the SQL you fell back to and the command that should
   have existed.

Label every claim that came from outside the dataset.
